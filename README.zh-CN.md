# Selkies Desk 0.4.1

macOS、Windows 和 Ubuntu 上的 Selkies 多服务器客户端。使用 Electron 内嵌服务器自己的网页，保留 Selkies 的视频、输入、显示设置、剪贴板和文件入口。左侧管理连接，右侧显示当前网页；同时只保留一个活动页面。

此版为测试版，只有 **Apple Silicon / arm64 的 macOS 包经过本机测试**，没有 Apple Developer ID 签名或公证，Windows 包没有代码签名。采用本地 ad-hoc 临时签名保证应用包内部一致性，不代表 Apple 验证了开发者身份。项目仓库由 ZhangJun 创建：[zinohome/Selkies-Desk](https://github.com/zinohome/Selkies-Desk)。已发布的版本在 [GitHub Releases](https://github.com/zinohome/Selkies-Desk/releases)，最新发布的是 0.4.0。0.4.1 的安装包已在开发机构建，尚未发布 Release。

## 0.4.1 的变化

- 侧栏分组可以折叠。
- 侧栏每个连接右侧有“···”按钮，点击直接打开该连接的设置，不会触发连接。
- 连接超时和自动重连次数可以在“设置 → 会话”里调整。
- 新增“设置 → 视频”：所有连接默认使用 H.264、45 FPS、CBR 固定码率 15 Mbps，可在这里统一修改。
- 工具栏上的状态改为“已连接”加连接时长（如 `12:34`），不再显示“页面已加载”。

“连接后进入全屏”是每个连接自己的选项，在连接设置里勾选；“连接成功后自动进入专注模式”是全局设置。两者互不影响。

## 0.4.0 的变化

- **快捷键修复**：焦点在远程桌面时快捷键不再失效，并且可以自定义。
- **中英文界面**：跟随系统语言，也可在设置里指定。
- **亮色、暗色、跟随系统**三种外观。
- 界面重新整理：去掉标语和大段说明，首页卡片显示上次会话缩略图，图标统一。
- 新增设置页、快速切换、断线自动重连、连接后自动专注、每个连接的全屏和自动连接选项。
- 可选把应用菜单快捷键（退出、关闭窗口、复制粘贴等）交给远端处理。

## 设置

从侧栏底部的“设置”进入，也可按 `⌘⌥,`（Windows / Ubuntu 为 `Ctrl+Alt+,`）。

设置窗口大小固定，左侧分为“通用、会话、快捷键、连接配置”四页。

| 项目 | 说明 |
| --- | --- |
| 语言 | 跟随系统 / 简体中文 / English，立即生效 |
| 外观 | 跟随系统 / 亮色 / 暗色，立即生效 |
| 连接成功后自动进入专注模式 | 默认开启 |
| 网络中断后自动重连 | 默认开启 |
| 自动重连次数 | 1–20，默认 6；关闭自动重连时不可改 |
| 连接超时（秒） | 3–120，默认 20。服务器在这段时间内没有任何响应，这次连接就算失败并按上面的次数重试 |
| 显示上次会话的缩略图 | 默认开启。缩略图以 JPEG 保存在用户数据目录的 `thumbnails/`，不加密、不导出；关闭此项会立即删除全部缩略图 |
| 把应用菜单快捷键发送给远端 | 默认关闭。开启后退出、关闭窗口、复制粘贴等组合键不再由本应用处理。`⌘Tab` 这类由操作系统保留的按键无法转发 |
| 视频 | 编码（默认 H.264）、帧率（10–240，默认 45）、码率控制（CBR 固定码率 / CRF 恒定质量，默认 CBR）、码率（1–200 Mbps，默认 15，仅 CBR 时有效）。对所有连接生效，可整体关闭 |
| 快捷键 | 逐项修改或恢复默认 |
| 连接配置 | 导入、导出 |

## 视频设置如何生效

Selkies 网页客户端把用户在它自己设置面板里选的值保存在浏览器存储中，并在开始串流时发给服务器。本应用在每次连接或重连时、远程页面自己的脚本运行之前，把“设置 → 视频”里的值写到同样的位置，效果等同于在 Selkies 面板里手动选了一遍。

- 因此这些设置每次连接都会被应用里的值覆盖。想改，请在应用设置里改；想完全交给 Selkies 面板，把“连接时应用以下视频设置”关掉。
- 服务器有最终决定权：服务器不支持的编码、超出它允许范围的数值，或被管理员锁定的项目，会回到服务器自己的值。
- 写入只发生在所配置服务器自己的页面上，由一个隔离的预加载脚本完成；它不向远程页面暴露任何接口，也没有通往本应用的通道。
- 键名和单位按 Selkies 当前的 WebSocket 模式客户端确定（`encoder`、`framerate`、`rate_control_mode`、`video_bitrate`，码率单位 kbit/s）。旧版 WebRTC 模式的 selkies-gstreamer 使用不同的设置方式，本功能对它无效。

## 安装与首次连接（macOS）

1. 取得本机生成的 DMG 后，使用对应的 `SHA256SUMS-0.4.1.txt` 核对文件。
2. 打开 DMG，将 **Selkies Desk.app** 拖到“应用程序”，弹出磁盘映像后启动。也可解压 `Selkies-Desk-0.4.1-mac-arm64.zip` 使用其中的应用。
3. 下载的未公证应用可能被 Gatekeeper 阻止。确认文件来源、校验和与风险后，可使用 macOS 系统提供的单个应用“仍要打开”流程；无需也不要全局关闭 Gatekeeper。若系统报告文件损坏，先重新下载核对校验和，或自行从源码构建。
4. 点击“新增连接”，填写名称和服务器地址，例如 `https://服务器地址:8443`。不带协议时默认 HTTPS。8443 与 8444 可以分别保存为两个条目。
5. 点击左侧条目连接。首次自签名证书会显示完整来源（含端口）、错误和 SHA-256 指纹；通过可信渠道核对后再确认。密码只在出现“服务器认证”时输入。

“页面已加载”表示网页加载完成，**不表示已经确认视频或远端键鼠正常**。视频连接、画质、分辨率、DPI 与流状态以 Selkies 自带面板为准。连接不自动重试，避免错误凭据造成认证循环。

## 日常操作

- 左侧栏参考 Windows App 的导航样式：产品名、搜索、新增连接、连接列表（圆角高亮和状态圆点），底部是设置入口和版本号。点击条目即可连接或切换。
- 侧栏里的连接按分组显示（有两个及以上分组时出现分组标题）。点击分组标题可以折叠或展开，标题上显示该组的连接数；折叠的分组里如果有正在使用的连接，标题上会有状态圆点。折叠状态保存在本机。搜索时会同时查找折叠分组里的连接。
- 首页是连接卡片，显示上次会话的缩略图、名称和地址；点击卡片连接，点击 `···` 编辑。搜索同时筛选侧栏和卡片。切换、断开或关闭都会销毁原页面并关闭网络连接；远端应用不会被主动结束。
- **连接成功后默认自动进入专注模式**，侧栏和工具栏同时收起。不需要时在“设置 → 会话”里关闭。
- macOS 上工具栏同时是窗口标题栏，可以直接拖动。专注模式下保留一条 28 DIP 的细标题条：左边是连接名称，右边是一组小图标（常规模式、侧栏、工具栏、全屏、重连、断开），空白处可拖动窗口。按钮就在标题条里，没有悬浮在标题栏上方的控件。
- **全屏只显示桌面**：无论侧栏和工具栏原来是否显示，进入全屏后都收起，远程页面占满整个全屏窗口；退出全屏后按原偏好恢复。带刘海的 MacBook 屏幕上，macOS 会把刘海所在的那一条（约 33 DIP）留黑，所有应用的全屏都是如此。远程桌面的分辨率是否跟随窗口变化由 Selkies 自己的显示设置决定。
- **悬浮球**：只要顶部工具栏隐藏（专注模式或全屏），桌面边缘就有一个半透明小圆球，做法和手机上的辅助触控相同。
  - 点一下，图标按钮沿一段紧贴圆球的弧带展开（全屏、重连、断开；窗口模式下多一个常规模式），圆球本身不移动，悬停显示名称和快捷键。再点一下圆球、按 Esc，或鼠标移开约 1.5 秒后收起。
  - 按住拖动，松手后吸附到最近的一条边，上、下、左、右都可以，并停在松手处对应的位置；位置会记住，下次打开仍在那里。
  - 弧带总是朝桌面内侧展开：靠左右边时在球的内侧上下排开，靠上边时在球下方、靠下边时在球上方左右排开。
  - 球在边上会留出弧带展开所需的空间，所以靠近角落时展开也不会被屏幕边缘截断，球也不会被挤走。
  - 靠上边时球距窗口顶端 10 DIP。macOS 全屏时只有鼠标碰到屏幕最顶端才会滑出菜单栏，点球不需要碰到那里，所以不受影响。在没有刘海的屏幕上全屏，窗口顶端就是屏幕顶端，球会再低 24 DIP，避免伸手点球时把菜单栏带出来盖住它。
- **快速切换**：按 `⌘⌥K`（Windows / Ubuntu 为 `Ctrl+Alt+K`）呼出面板，输入名称或地址，回车连接。
- **快捷键在焦点位于远程桌面时同样生效**。它们由应用先于远端网页处理，其他按键照常发送给远端。所有快捷键都可以在“设置 → 快捷键”里修改或恢复默认；新快捷键需要包含 Ctrl、Alt 或 ⌘，或者是功能键，并且不能与其他命令重复。
- **断线自动重连**：服务器不可达、连接超时等网络类错误会自动重试（默认 6 次，可设置），等待时间依次为 2、4、8、16 秒，之后每次 30 秒，界面显示原因和进度，可随时点“停止”。证书或认证问题不会自动重试。远端页面已加载后的视频流中断由 Selkies 网页自己处理。
- 每个连接可以单独设置“连接后进入全屏”和“启动应用时自动连接”；同一时间只有一个连接可以设为自动连接。
- 工具栏的滑块图标可编辑、删除连接、清除记住的密码和撤销证书信任。删除需二次确认，并清理该连接的网页数据和缩略图。
- 保留远端原有剪贴板、文件上传和下载入口。**剪贴板默认允许**：当前活动连接的精确来源可直接读写系统剪贴板，无需点击允许或拒绝，持续轮询和并发请求也不弹窗。默认允许仅适用于剪贴板，不扩展到其他来源、非活动页面、本地管理页或后台 worker。
- 摄像头、麦克风、鼠标锁定等其他支持的权限仍按连接和精确来源询问，允许与拒绝决定在当前页面会话复用，同类并发请求合并为一次询问；不支持的权限直接拒绝。刷新、重连、切换、断开、页面销毁或退出会清除决定并关闭过期权限弹窗。要重新授权，请点击“重连”或使用 `⌘⌥R`。允许麦克风不会同时允许摄像头。
- 新窗口链接会先确认，再交给系统浏览器打开；不允许其替换本地管理页。跨来源的顶层跳转会被阻止，请为新来源另建连接。

## 会话、密码与证书

每个连接 ID 对应独立的持久分区。同一地址上的两个账号也需保存为两个条目，才能分别保留 Cookie、localStorage、认证缓存与 Selkies 设置。持久 Cookie 的期限由服务器决定；服务器设置的会话 Cookie 不会被客户端擅自延长。

密码只在主进程处理。勾选“加密记住密码”使用 Electron 45 的异步 safeStorage API，将密文保存到用户数据目录。safeStorage 使用 macOS Keychain 保护加密密钥，**不是每个服务器密码各占一条 Keychain 记录**。不可用或加密失败时，只保留本次会话密码，不保存明文。更新应用签名、身份或迁移到另一台 Mac 可能要求 Keychain 重新授权或重新输入密码；配置导出不迁移密钥。

信任绑定连接 ID、精确 HTTP(S) 来源和证书 SHA-256 指纹；对应的 WS/WSS 握手遵循同一来源规则。证书更换须重新确认。修改来源会撤销原证书信任并清除旧凭据；修改用户名也会清除旧凭据及认证缓存。网页设置仍按连接保留，账号需要完全分离时请建立新连接。

远端页面启用 sandbox、contextIsolation 和 webSecurity，关闭 Node integration，没有本地 preload 或管理 IPC。管理 IPC 验证主窗口、主 frame、精确本地页面 URL 和字段。悬浮操作条是独立本地 WebContentsView，只能调用布局与当前会话操作，不能编辑连接、读取文件或提交认证答案。向其他来源的请求会剥离 Authorization 与 Cookie，不向代理提供服务器凭据，不全局忽略 TLS。

用户数据默认位于 `~/Library/Application Support/Selkies Desk/`：

- `connections.json`：连接、窗口尺寸、布局偏好和固定证书的指纹；不含密码。旧版文件无需手动迁移。
- `credentials.enc.json`：加密凭据；不要当成可跨设备直接解密的备份。
- `thumbnails/`：各连接上次会话的缩略图（未加密的 JPEG，文件权限仅限当前用户）；在设置里关闭缩略图会删除此目录。
- `Partitions/`：各连接的网页存储；可能含服务器 Cookie 等敏感会话数据，请妥善保护。

上述路径是本机使用说明；本次产物按用户要求只保留在开发环境。应用打不开且配置校验报错时，先退出应用并备份整个数据目录，再检查 `connections.json` 的格式或恢复已知良好的备份；应用不会静默覆盖损坏配置。

## 配置导入导出

导入和导出在“设置 → 连接配置”里，也可以从“连接”菜单进入。语言、外观、快捷键等设置和缩略图不包含在导出文件中。0.4.0 导出的文件多了“连接后进入全屏”和“启动时自动连接”两个字段，0.3.0 及更早版本无法导入；旧版本导出的文件可以直接导入 0.4.0。导入的条目不会继承“启动时自动连接”。

通过左下角按钮选择 JSON 文件。导出排除密码、认证缓存、Cookie、权限和证书信任；保留连接名称、地址、用户名、分组、备注及 ID。

导入先校验版本和字段，确认后全部作为新连接添加，重新生成 ID。已有连接保持原样，重名条目加“（导入 2）”等后缀；不会复用原会话。最多 200 条连接，文件不超过 1 MB。地址仅接受 HTTP(S)，不接受 URL 用户名、密码、查询参数或片段；需要令牌等额外登录流程的服务暂不在此版范围内。

```json
{
  "version": 1,
  "connections": [
    {
      "name": "研发工作台",
      "url": "https://server.example:8443/",
      "group": "开发",
      "notes": "",
      "username": ""
    }
  ]
}
```

## 从源码构建

在 Mac 上解压源码 ZIP，进入 `selkies-desk` 目录，或克隆上述仓库并进入仓库根目录：

```sh
npm ci
npm test
npm start
npm run package          # macOS arm64 DMG + ZIP
npm run package:mac-x64  # macOS Intel DMG + ZIP
npm run package:win      # Windows x64 安装程序
npm run package:linux    # Ubuntu amd64 deb
npm run package:all      # 以上全部
```

四种安装包都可以在 Apple Silicon Mac 上直接生成，不需要 Wine、Docker 或 Rosetta：构建配置选用了带 arm64 版 makensis 的 NSIS 工具集（`toolsets.nsis`），deb 使用 electron-builder 自带的 arm64 版 fpm。首次构建会下载对应系统的 Electron 运行时和这些工具。

依赖已由 `package-lock.json` 锁定。开发机使用 Node 26.9.0、npm 11.19.1、Xcode Command Line Tools；Electron 固定 45.2.3。Electron 首次使用可能需要下载运行时。开发依赖的安装脚本若被 npm 策略阻止，请审查对应包后按本机策略批准；不要在公共环境全局放开所有安装脚本。

macOS 包使用 ad-hoc 签名，所有打包命令都带 `--publish never`。不会创建远程仓库、发布或调用 Apple 公证服务。安装包的系统版本下限设为 Electron 自带的 macOS 13；**实际只在本机 macOS 27.2 / arm64 验证，未声称 macOS 13–26、Intel Mac、Windows 或 Ubuntu 实测通过**。

重建图标可运行 `node scripts/make-icon.mjs`（需要 macOS 的 Swift、sips 和 iconutil，同时生成 Linux 用的多尺寸 PNG）；图标产物已包含在源码中，正常构建无需运行此命令。

完整 Electron 测试仅使用两个本地 HTTP 模拟端及一个可轮换证书的 HTTPS 模拟端，不连接用户服务器、不使用真实密码。测试期间临时备份并恢复系统剪贴板，测试配置和临时证书在结束时清理。原生文件确认与部分权限选择在自动化中替换为确定的选择；权限取消回归另外使用真实 macOS 原生弹窗；下载内容和配置落盘由实际 Electron API 完成。
